# Oracle Wallet Provisioning Connector

Oracle databases and middleware read their TLS certificates and private keys from Oracle Wallets. Updating those wallets by hand at every renewal is slow and error-prone, and a missed update can break encrypted connections. The Secur Solutions Oracle Wallet Provisioning Connector automates the secure provisioning of SSL/TLS certificates and private keys from Next-Gen Trust Security directly into your Oracle Wallets.

**Value Highlights**

- **Automate wallet updates**: Deliver certificates and private keys issued by Next-Gen Trust Security into Oracle Wallets without manual import steps.
- **Prevent outages**: Keep wallets current when certificates are renewed, so Oracle services do not run on expired certificates.
- **Reduce handling of private keys**: Move keys into wallets through an automated process rather than by copying files between administrators.
- **Apply policy consistently**: Certificates provisioned to Oracle Wallets are issued and tracked under your Next-Gen Trust Security policy.

**How it Works**

The connector extends Next-Gen Trust Security so that, when a certificate is issued or renewed, the certificate and private key are placed in the configured Oracle Wallet. Contact Secur Solutions Group for access to the Provisioning Connector and its setup guide.

**Solution Components**

- Next-Gen Trust Security
- Oracle Wallet on the target Oracle systems
