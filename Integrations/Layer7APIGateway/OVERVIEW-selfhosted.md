# Layer7 API Gateway

APIIDA, a specialist in API, identity and access software solutions, has built a direct integration with the Venafi Platform and Broadcom Layer7 API Management (formally CA) for automation not previously available for Layer7 API Gateway customers.

  

**SOLUTION HIGHLIGHTS**

- **Centrally manage** and secure corporate assets 
- **Prioritize traffic **to help ensure APIs remain available and responsive
- **Translate between legacy and new **applications and data
- **Clustered architecture** allows linear scalability across multiple Gateways, with automatic failover, application level throttling and prioritization
- **Handles migrations **across dev/test/production with global management tools, and integrates with enterprise BI, analytics, and reporting tools
- **Multiple form factors/deployment models **with support for a wide range of platforms, including Docker, AWS and Azure
- **Plug-in framework **to add new transports and identity providers, and deep integration with enterprise management and BI products

  

**SOLUTION OVERVIEW**

API gateways are important ingredients to Global 5000 DevOps, cloud, PSD2, and digital transformation strategies. API gateways use large numbers of machine identities -TLS keys and digital certificates - to establish trust and privacy. But API gateways, including Broadcom Layer 7 API Gateways, have not included machine identity protection to provide security teams the intelligence of how machine identities are being used. Nor have they provided network operations teams with the automation to eliminate time-consuming and error prone TLS certificate lifecycle functions. 

  

Venafi customers need a current, supported driver in order to integrate the Broadcom Layer7 API Gateway with machine identity management. Now with this driver that supports automation, Venafi customers can achieve significantly reduced operational costs and risks.
