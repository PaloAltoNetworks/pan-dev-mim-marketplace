# Jamf Pro

Managing certificates across every enterprise Apple device is harder than it looks. Device management teams are not PKI experts and need simple access to certificates, while security teams need policy enforced, certificates drawn only from approved sources, and a "kill switch" to remove them. Jamf Pro brings device management and PKI together by automating requests to Next-Gen Trust Security for certificate issuance, renewal and revocation.

**Value Highlights**

- **Secure devices at scale**: Deliver high-speed, high-scale identity security to devices for Zero Trust.
- **Operate with agility**: Issue or revoke certificates automatically for thousands of devices.
- **Set one baseline**: Give corporate-owned and BYOD devices the same secure baseline level of trust.
- **Target the right devices**: Use configuration profiles and flexible scoping to apply certificate configurations to specific groups of devices.
- **Keep security in control**: Revoke certificates from Next-Gen Trust Security when a device should lose access.

**How it Works**

Jamf Pro sends certificate requests to Next-Gen Trust Security for issuance, renewal and revocation, and delivers the resulting certificates to devices through configuration profiles scoped to the right device groups.

**Solution Components**

- Next-Gen Trust Security
- Jamf Pro and enrolled Apple devices (macOS, iOS and iPadOS)

**About Jamf**

[Jamf](https://www.jamf.com/) builds Apple device management and security software for organizations. Jamf developed this integration with support from the Machine Identity Management Development Fund.
