# Certificate Manager SaaS Event Log to ServiceNow

Teams that run IT operations in ServiceNow often have no direct access to Certificate Manager, SaaS, so certificate problems reach them late or through ad hoc notifications. This integration takes any Certificate Manager, SaaS log event and creates a ServiceNow Event Management event from it, so those teams see and act on certificate activity in the tools they already use.

**Value Highlights**

- **Customize completely**: Turn any Certificate Manager, SaaS event into a ServiceNow event and act on it there.
- **Remove manual alerting**: Stop building separate notifications and alerts for different teams.
- **Extend visibility**: Give teams without access to Certificate Manager, SaaS insight into certificate activity.
- **Find root causes faster**: Use ServiceNow alerts to understand unexpected behavior and its impact on the business.

**How it Works**

Certificate Manager, SaaS log events are sent to ServiceNow Event Management as events. In ServiceNow, event rules turn those events into alerts, which you can configure to trigger actions such as incidents or notifications. Use the support contact on this listing for setup details.

**Solution Components**

- Certificate Manager, SaaS
- ServiceNow Event Management

**Certificate Manager, SaaS is the product formerly known as Venafi TLS Protect Cloud**
