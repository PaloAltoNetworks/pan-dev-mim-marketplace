# Certificate Enrollment Client (Windows, Linux, MacOS) with Zero Touch PKI

Getting device certificates onto Windows, Linux and macOS endpoints often depends on manual requests or platform-specific tooling. This thick client application simplifies and secures device identity management by automating certificate enrollment from Zero Touch PKI, using identities from Microsoft Entra ID and Windows Active Directory.

**Value Highlights**

- **Automate enrollment**: Enroll device certificates without manual requests.
- **Cover mixed fleets**: Use one client on Windows, Linux and macOS.
- **Use existing identities**: Base enrollment on devices and users known to Microsoft Entra ID and Windows Active Directory.
- **Issue from Zero Touch PKI**: Get certificates from the Zero Touch PKI hosted certificate authority.

**How it Works**

The client runs on each endpoint and requests a certificate from Zero Touch PKI, using Microsoft Entra ID or Windows Active Directory to identify the device. Secur Solutions Group lists this client as available on request. Use the support contact on this listing for availability and setup details.

**Solution Components**

- Zero Touch PKI
- Microsoft Entra ID or Windows Active Directory
- Windows, Linux and macOS endpoints
