# YubiKey Certificate Manager for Windows

Putting certificates onto YubiKey hardware tokens is often a manual, technical task, which slows rollout and leads to inconsistent results. Secur Solutions' YubiKey Certificate Manager for Windows is a Windows client application that simplifies provisioning and installing digital certificates from Certificate Manager, Self-Hosted onto YubiKey devices, so the private key and certificate are protected in hardware.

**Value Highlights**

- **Simplify provisioning**: Load certificates onto a YubiKey from an intuitive Windows client.
- **Protect keys in hardware**: Keep the certificate and its private key on the YubiKey device.
- **Apply central policy**: Issue YubiKey certificates through Certificate Manager, Self-Hosted so they follow your organization's policies.
- **Reduce manual effort**: Remove error-prone manual steps from token enrollment.

**How it Works**

The Windows client connects to Certificate Manager, Self-Hosted to request the certificate and installs it onto the YubiKey inserted in the workstation. The application is a paid offering from Secur Solutions Group. Contact the partner for access and setup guidance.

**Solution Components**

- Certificate Manager, Self-Hosted
- YubiKey devices
- Secur Solutions YubiKey Certificate Manager for Windows client
