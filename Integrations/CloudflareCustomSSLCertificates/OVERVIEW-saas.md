# Cloudflare Custom SSL Certificates

Businesses that serve traffic through Cloudflare edge services want more control over the certificates used there, and a single process for managing certificates across all environments. This machine connector lets Certificate Manager, SaaS discover and provision custom SSL certificates to Cloudflare, so edge certificates follow the same policies as the rest of your inventory.

**Value Highlights**

- **Connect multiple accounts**: Connect to several Cloudflare accounts with API tokens.
- **Automate the lifecycle**: Provision and renew Cloudflare edge certificates without manual work.
- **Discover custom certificates**: Find the custom certificates in your Cloudflare zones.
- **Use your own public CA**: Issue edge certificates from your chosen public CA through Certificate Manager, SaaS, under enterprise security policy.
- **Ease compliance**: Replace manual steps with automated, auditable workflows.

**How it Works**

Cloudflare is a native machine type in Certificate Manager, SaaS. You add a Cloudflare machine with an API token, and Certificate Manager, SaaS discovers the custom certificates in your Cloudflare zones and provisions new and renewed certificates to them. See the Documentation tab for setup.

**Applicability**

For businesses and enterprise customers who want more control and flexibility over certificates used with Cloudflare edge services.

**Solution Components**

- Certificate Manager, SaaS
- Cloudflare edge services
