# Cloudflare Custom SSL Certificates

Businesses that serve traffic through Cloudflare edge services want more control over the certificates used there, and a single process for managing certificates across all environments. This machine connector lets Next-Gen Trust Security discover and provision custom SSL certificates to Cloudflare, so edge certificates follow the same policies as the rest of your inventory.

**Value Highlights**

- **Connect multiple accounts**: Connect to several Cloudflare accounts with API tokens.
- **Automate the lifecycle**: Provision and renew Cloudflare edge certificates without manual work.
- **Discover custom certificates**: Find the custom certificates in your Cloudflare zones.
- **Use your own public CA**: Issue edge certificates from your chosen public CA through Next-Gen Trust Security, under enterprise security policy.
- **Ease compliance**: Replace manual steps with automated, auditable workflows.

**How it Works**

Cloudflare is a native machine type in Next-Gen Trust Security. You add a Cloudflare machine with an API token, with the connector running in the cloud or on a VSatellite in your network, and Next-Gen Trust Security discovers the custom certificates in your Cloudflare zones and provisions new and renewed certificates to them. See the Documentation tab for setup.

**Applicability**

For businesses and enterprise customers who want more control and flexibility over certificates used with Cloudflare edge services.

**Solution Components**

- Next-Gen Trust Security
- Cloudflare edge services
