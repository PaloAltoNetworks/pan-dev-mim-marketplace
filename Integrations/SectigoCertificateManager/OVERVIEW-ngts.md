# Sectigo Certificate Manager

The rapid growth of HTTPS and enterprise encryption means organizations need visibility, automation and control over every certificate, along with the agility to work with more than one certificate authority. Next-Gen Trust Security integrates with Sectigo Certificate Manager (SCM), so you can automate the full lifecycle of Sectigo certificates under central policy and extend encryption to more applications in more places.

**Value Highlights**

- **Automate the full lifecycle** of Sectigo certificates, from request and issuance to renewal and revocation.
- **Gain visibility** into the demand for, usage of and workflow around certificate services.
- **Enforce policies** with automated workflow and detailed logging.
- **Keep CA agility**: Manage Sectigo certificates alongside certificates from your other CAs.
- **Use the native Sectigo API** for certificate requests.

**How it Works**

Next-Gen Trust Security includes a Sectigo Certificate Manager CA connector that you add as a certificate authority and reference from your issuing templates. It authenticates with an API key for a Sectigo administrator account set to automatically approve certificate requests. Some product types, such as EV, may still require approval in the SCM web portal. See the Documentation tab for setup.

**Solution Components**

- Next-Gen Trust Security
- Sectigo Certificate Manager
