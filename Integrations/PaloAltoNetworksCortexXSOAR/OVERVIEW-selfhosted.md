# Palo Alto Networks Cortex XSOAR

Machine identities such as TLS certificates are a first-class cybersecurity asset for any Global 5000 organization. The sheer volume of certificates that power the availability and security of an enterprise IT environment is in the millions and continue increasing as shorter life span of certificates are adopted. Managing machine identities is a top priority for modern Security Operations Center (SOC) teams that can only function with automation and intelligence brought by XSOAR.

This integration between Venafi and Palo Alto Networks Cortex XSOAR offers an industry-leading solution for efficient management and automation of machine identities, increasing efficacy, robustness and speed in the Security Operations Center (SOC). By using this solution, SOC teams will gain the ability to manage their digital certificates and keys within the Cortex XSOAR platform, making full use of automation to decrease time spent on manual management and increase operational efficiency.

This integration provides a powerful and extensible framework for the SecOps teams, increasing their mitigation speed and reducing the attack surface. The primary outcome is a comprehensive, automated, and central control over machine identities, decreasing the risk of outages and security breaches caused by mismanagement of these crucial assets.

**Applicability**

The combined solution can benefit any organization using Certificate Manager, Self-Hosted and Palo Alto Networks Cortex XSOAR, looking for ways to automate and optimize their cybersecurity asset management. Expectations include an increase in operational efficiency, reduction in human error, and stronger security posture with centralized control over machine identities.

**Value Highlights**

- Streamlined automation of certificate enrollment, provisioning, and lifecycle management.
- Centralized control and auditability, preventing misuse, and compromise of machine identities.
- Rapid mitigation of issues, minimizing machine identity related outages.
- Enhanced agility in cybersecurity operations with modernized and efficient machine identity management strategy.

**Solution Components**

- Certificate Manager, Self-Hosted (formerly knowns Certificate Manager, Self-Hosted)
- Palo Alto Networks Cortex XSOAR

**How it Works**

This solution requires an active license for both Venafi and Cortex XSOAR. It involves API-based integration where Venafi feeds machine identity information into Cortex XSOAR, which can then be used within automated workflows on the platform.

- Ensure Venafi and Cortex XSOAR licenses are active
- Link Venafi with Cortex XSOAR through the API
- Begin using the integrated system
