# Swimlane

Keeping machines up to date, protected, monitored and decommissioned demands time that many security teams don't have, so machine identity issues are often delayed or forgotten. This API integration between Swimlane and Certificate Manager, Self-Hosted lets you respond to machine identity alerts with automated workflows that can be customized to fit any environment.

**Value Highlights**

- **Cut investigation time**: Reduce the average time spent investigating and remediating machine identity alerts.
- **Reduce risk quickly**: Recover from breaches at machine speed using automated workflows.
- **Fight alert fatigue**: Automate actions and free analysts for other work.
- **Manage certificates from Swimlane**: Renew, request, search, validate or dissociate certificates.
- **Act on SSH findings**: Get SSH critical alerts and policy violations, or search for SSH key details.
- **Feed your playbooks**: Ingest members, memberships, identity attributes and identity details into Swimlane workflows.

**How it Works**

Swimlane ingests alerts and findings from Certificate Manager, Self-Hosted through its API, giving analysts one central place with all relevant case data from across integrated products. Analysts review the findings and remediate with automated workflows, including rotating TLS, SSH and code signing machine identities from within Swimlane.

**Solution Components**

- Certificate Manager, Self-Hosted
- Swimlane security automation (SOAR) platform

**About Swimlane**

Swimlane provides security orchestration, automation and response (SOAR) that connects disparate security tools so teams can respond at machine speed. Learn more at [swimlane.com](https://swimlane.com/).
