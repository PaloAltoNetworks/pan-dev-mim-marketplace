# Quantum-safe VCert

ISARA provides a VCert extension for the Venafi Platform that enables Quantum-safe machine identities and crypto agility using the ISARA Radiate Toolkit and ISARA Catalyst Agile Certificate Methodology with certificate service providers.

  

**SOLUTION HIGHLIGHTS**

- **Protect critical assets** with Quantum-safe security
- **Lower migration costs **with backward compatible hybrid certificates
- **Improve crypto agility **posture
- **Standard Go Crypto package **with added Dilithium digital signature algorithm support
- **Standard Go Crypto/x509 package **supports the Dilithium algorithm for all certificates in the chain and single-tree HSS for CA certificates
- **Standard Go Crypto/x509 package **with support for [Recommendation ITU-T X.509 | ISO/IEC 9594-8](https://www.itu.int/ITU-T/recommendations/rec.aspx?rec=X.509) standard compliant hybrid certificate format

  

**SOLUTION OVERVIEW**

ISARA, the world’s leading provider of agile quantum-safe security solutions, has enabled Venafi customers with quantum-safe cryptography and machines identities via a VCert Go extension. By creating an extension for VCert Go to support quantum-safe cryptography, developers will now be able to generate hybrid certificates that contain both today's standard algorithms and quantum-safe algorithms in preparation for the future.

  

Agile Quantum-safe Machine Identity Orchestration using VCert allows you to:

- Generate Quantum-safe cryptographic keys 
- Create Certificate Signing Requests (CSRs) for hybrid certificates
- Verify hybrid certificates using primary and alternate algorithms
