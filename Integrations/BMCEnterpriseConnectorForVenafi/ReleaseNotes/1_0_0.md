#### Availability
- Initial release for Certificate Manager Self-Hosted.

#### Supported Lifecycle Actions
- Certificate provisioning and lifecycle management for RACF, TSS, and ACF2 environments on z/OS via BMC's Enterprise Connector for Venafi.

#### Included Drivers
- One Adaptable Driver script per supported Enterprise Connector for Venafi version: SPE2304, SPE2307, SPE2310, SPE2401, SPE2404, SPE2407, SPE2410, SPE2501, SPE2504, and SPE2507. Use the script matching your installed Enterprise Connector for Venafi version — see the OVERVIEW for the full version-to-driver mapping.

#### Limitations
- Each driver script requires BMC-supplied DLLs matching its Enterprise Connector for Venafi version; mismatched driver/DLL pairs are not supported.
