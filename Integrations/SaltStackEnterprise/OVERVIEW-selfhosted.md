# SaltStack Enterprise

Orchestration enables enterprises to run fast; however, automating HTTPS has always required custom code and integration. Working closely with SaltStack, Venafi makes it fast and easy to accelerate continuous delivery and scale applications using HTTPS.

  

**SOLUTION HIGHLIGHTS**

- **Eliminate hassle **and risks of requesting and installing keys and certificates with native SaltStack integration 
- **Elastically scale **development without the constraints of traditional certificate pipelines 
- **Automate the use of HTTPS **with policy-enforced decision making in the cloud 
- **Fast setup **without requiring external configuration 
- **High-speed certificate issuance **pipeline available with native SaltStack Pillar integration 
- **Native DevOps workflow** for continuous service delivery and automation 

  

**SOLUTION OVERVIEW**

SaltStack develops intelligent orchestration software to help enterprise IT organizations more efficiently secure and manage all aspects of the software-defined data center. Working closely with SaltStack, Venafi makes it fast and easy to accelerate continuous delivery and scale applications using HTTPS.
