# IBM DataPower Gateway

This integration lets Certificate Manager, Self-Hosted automate the full certificate lifecycle on IBM DataPower Gateway appliances, provisioning keys and certificates and binding them to the SSL profiles that secure DataPower workloads.

  

**SOLUTION HIGHLIGHTS**

- **Automate **enrollment, provisioning, monitoring, renewal, and revocation of certificates on DataPower
- **Provision keys and certificates **including private key and CSR generation, then installation onto the device
- **Bind to SSL profiles **by associating certificates with SSL Client, Server, and Proxy profiles

  

**SOLUTION OVERVIEW**

IBM DataPower Gateway is a security and integration gateway that protects and manages APIs, web services, mobile, B2B, and cloud workloads. Using a DataPower application object configured in Venafi, Certificate Manager, Self-Hosted monitors, enrolls, and provisions certificates and keys on connected appliances. During provisioning it generates the private key and CSR, retrieves the certificate from the CA, installs both on the device, creates Identification and Validation Credential objects, and associates the certificate with the configured SSL Client, Server, or Proxy profiles. Certificates can also be provisioned into the DataPower trust store, and renewed manually or automatically ahead of expiration to help prevent outages caused by expired certificates.

**ABOUT IBM**

IBM is a global technology company whose DataPower Gateway provides a purpose-built appliance for securing and integrating enterprise workloads through message security, transformation, and protocol bridging. Centralized management through Venafi gives DataPower teams a single certificate inventory that improves tracking, streamlines renewal and installation, and simplifies decommissioning while applying consistent policy.

**Certificate Manager, Self-Hosted is the product formerly known as Venafi Trust Protection Platform**
