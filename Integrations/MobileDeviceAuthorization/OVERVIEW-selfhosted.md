# Mobile Device Authorization

Venafi gives security and operations teams greater control with consistent certificate issuance polices, consolidated user-level visibility and powerful killswitch technology for , VPN, Wi-Fi and other certificates.

  

**SOLUTION HIGHLIGHTS**

- **Gain visibility** down to the user level for all certificates 
- **Get a running start **with existing CAs and directory import 
- **Stop unauthorized access **with single kill switch 
- **Validated SCEP integration **for issuing multi-profile and policy-enforced certificates 
- **Kill switch **to revoke all certificates for a given individual across CAs 
- **Import and sync** with directory services

  

**SOLUTION OVERVIEW**

From Wi-Fi and VPN to MDM/EMM management, certificates are being used more frequently to authenticate mobile devices and their users. Venafi gives security and operations teams greater control with consistent certificate issuance polices, consolidated user-level visibility and powerful killswitch technology for , VPN, Wi-Fi and other certificates.
