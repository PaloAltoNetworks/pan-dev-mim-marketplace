# Recursive Certificate Discovery

Certificates stored as files on Linux servers are easy to lose track of, especially when applications keep them in deep or non-standard directory trees. Certificates you cannot see cannot be renewed on time, and an unknown expiring certificate can cause an outage. The Recursive Certificate Discovery connector from Secur Solutions Group automates discovery of certificates stored on Linux file systems and brings them into Certificate Manager, SaaS.

**Value Highlights**

- **Find hidden certificates**: Scan a root folder and every directory beneath it, not just a fixed list of paths.
- **Build a complete inventory**: Add certificates found on Linux file systems to Certificate Manager, SaaS.
- **Prevent surprise expirations**: Once discovered, certificates can be monitored and renewed before they expire.
- **Reduce manual effort**: Replace hand-maintained spreadsheets of certificate file locations with automated discovery.

**How it Works**

You specify a root folder path on the target Linux system. The connector recursively scans that folder and all child directories, locates certificate files in PEM format, and reports them to Certificate Manager, SaaS for inventory and monitoring.

**Solution Components**

- Certificate Manager, SaaS
- Linux servers that store certificate files
