#### Added
- Downloadable driver package containing the ACME Adaptable CA driver, a sample CA configuration file, and a full installation and usage guide.
- `Proxy` and `ProxyBypass` configuration options, including proxy authentication.
- An `AllowMeToSave` option to bypass the service address when troubleshooting validation issues.

#### Changed
- Password-type configuration fields are now masked when written to logs.
