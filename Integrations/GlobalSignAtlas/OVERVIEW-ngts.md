# GlobalSign Atlas

Enterprises need trusted certificates at high volume, especially in DevOps environments, without losing control over policy or visibility into what has been issued. GlobalSign Atlas is a cloud-native certificate authority platform built for scale and automation.

Next-Gen Trust Security connects to GlobalSign Atlas as a certificate authority, so teams can request GlobalSign certificates through Next-Gen Trust Security while it enforces enterprise policy and tracks every certificate through its lifecycle.

**Value Highlights**

- **Automate the certificate lifecycle** to reduce manual effort and keep issuance within the defined scope.
- **Enforce enterprise policy** on every certificate requested from GlobalSign Atlas.
- **Meet high-volume demand** from DevOps environments with certificates from a trusted public CA.
- **Centralize oversight** of certificate usage to prevent unexpected expirations.
- **Use the native GlobalSign Atlas API** for consistent issuance.

**How it Works**

An administrator generates an encrypted API credentials file in the GlobalSign Atlas portal and uploads it when adding GlobalSign as a certificate authority in Next-Gen Trust Security. After validation, Next-Gen Trust Security shows the GlobalSign validation policy that requests must meet, and certificates requested through Next-Gen Trust Security are issued by GlobalSign Atlas and managed through their lifecycle. See the Documentation tab for setup.
