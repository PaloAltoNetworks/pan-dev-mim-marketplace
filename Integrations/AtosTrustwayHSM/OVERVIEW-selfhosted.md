# Atos Trustway HSM

Most private keys are stored in files on the systems they secure, which makes them susceptible to theft. A hardware security module (HSM) generates, stores and uses keys inside a hardened appliance and simplifies compliance, because auditors understand its security benefits. But HSMs also add a layer between your systems and your keys that increases management complexity.

The integration between Certificate Manager, Self-Hosted and Atos Trustway Proteccio HSM removes that complexity. Certificate Manager, Self-Hosted orchestrates hardware-protected machine certificates across the enterprise, so you own and control the keys that protect your machine identities and the data they secure.

**Value Highlights**

- **Eliminate the risk** of cryptographic keys being stolen from file systems or memory.
- **Ensure consistent use** of strong cryptographic keys.
- **Facilitate compliance** with data security regulations.
- **Store keys in a secure vault** backed by a true random number generator with strong entropy.
- **Rely on certified hardware** with Common Criteria EAL4+, NATO Secret, EU Restricted, ANSSI and FIPS 140-2 Level 3 certifications.

**How it Works**

Certificate Manager, Self-Hosted connects to the Trustway Proteccio HSM through its PKCS#11 interface. Keys for the machine identities you choose are generated and stored in the HSM, while Certificate Manager, Self-Hosted automates the certificate lifecycle around them.

**Solution Components**

- Certificate Manager, Self-Hosted
- Atos Trustway Proteccio netHSM

**About Atos**

Atos Trustway Proteccio is a multi-user network HSM for encryption, signature, hashing, key generation and key wrapping. The Trustway product line is now offered by [Eviden](https://eviden.com/), an Atos Group business.
