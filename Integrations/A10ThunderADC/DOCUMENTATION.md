# A10 Thunder

## Introduction

> 💡️ **NOTE**
>
> This integration supports ACOS v5.2.1 and above.

HTTPS encryption is more prevalent than ever but can be difficult to scale. A10 and Venafi have teamed up to make it easy to automate the use of keys and certificates for application teams using the following products from A10:

- **A10 Networks Thunder ADC -** A high-performance application delivery controller (ADC) that delivers secure, scalable, and highly available applications.

- **A10 Networks Thunder SSLi -** A10 Thunder SSLi (SSL Insight) decrypts traffic, enabling security devices to analyze all enterprise traffic without compromising performance

## Configuration

For configuration instructions, please refer to the official Venafi product documentation for [Adaptable Application drivers](https://docs.venafi.com/Docs/current/TopNav/Content/Drivers/cco-drivers-AdaptableApp-Overview.php).
