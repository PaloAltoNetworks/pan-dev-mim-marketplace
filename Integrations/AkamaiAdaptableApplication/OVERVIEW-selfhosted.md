# Akamai Adaptable Application

The Akamai Adaptable Application Driver is a Certificate Manager, Self-Hosted driver that communicates with the Akamai Certificate Provisioning System API to discover and provision certificates.

  

**SOLUTION HIGHLIGHTS**

- **Streamlines operations **through automated discovery
- **Increases visibility **by including the Akamai certificates in the unified Venafi platform
- **Increases security **through visibility into all machine identities
- **Imports** all production certificates
- **Supports multi-stacked RSA/ECC **certificates issued by DigiCert and managed by Akamai

  

**SOLUTION OVERVIEW**

Akamai offers certificate management along with the other edge services they provide. Visibility into the certificates created and stored on the Akamai system is important for full risk analysis. This application driver will discover all the certificates on the production networks at Akamai and import them into the Certificate Manager for full visibility in one unified application.

  

The driver supports the onboard discovery and provisioning functions of an application driver. Onboard discovery allows the user to import all the production certificates from the Akamai CPS into the platform, and provisioning allows new and renewed certificates to be issued directly to Akamai from Certificate Manager. Optional adaptable workflows are included to require approval before certificate changes are acknowledged in Akamai, and to orchestrate dual-stack RSA/ECC certificate deployments.
