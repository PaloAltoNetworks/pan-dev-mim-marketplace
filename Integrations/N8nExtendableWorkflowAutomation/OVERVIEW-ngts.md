# n8n Extendable Workflow Automation

DevOps and engineering teams move fast, and learning new tools and wiring applications together slows delivery. Security teams also lack a way to offer services such as certificate management that fit those workflows. With support from the Machine Identity Management Development Fund, n8n, a no-code workflow automation platform with visual design, connects Next-Gen Trust Security to its existing integrations with popular software and SaaS services, so teams can request and use certificates inside their automated workflows.

**Value Highlights**

- **Automate without code**: Build certificate workflows visually instead of writing scripts.
- **Include certificates in workflows**: Request and retrieve certificates as steps in n8n workflows.
- **Connect certificate consumers**: Combine certificate steps with n8n integrations for the services that use certificates.
- **Give DevOps a security service**: Let engineering teams use certificate management in the tools they already automate.

**How it Works**

n8n workflows connect Next-Gen Trust Security with the n8n integrations for the software and SaaS services that consume certificates, so certificate requests and renewals become steps in a visual workflow.

**Solution Components**

- Next-Gen Trust Security
- [n8n](https://n8n.io/)
