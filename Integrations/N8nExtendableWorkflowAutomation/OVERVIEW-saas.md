# n8n Extendable Workflow Automation

DevOps and engineering teams move fast, and learning new tools and wiring applications together slows delivery. Security teams also lack a way to offer services such as certificate management that fit those workflows. With support from the Machine Identity Management Development Fund, n8n, a no-code workflow automation platform with visual design, connects Certificate Manager, SaaS to its existing integrations with popular software and SaaS services, so teams can request and use certificates inside their automated workflows.

**Value Highlights**

- **Automate without code**: Build certificate workflows visually instead of writing scripts.
- **Include certificates in workflows**: Request and retrieve certificates as steps in n8n workflows.
- **Connect certificate consumers**: Combine certificate steps with n8n integrations for the services that use certificates.
- **Give DevOps a security service**: Let engineering teams use certificate management in the tools they already automate.
- **React to events**: Start workflows from Certificate Manager, SaaS events with the trigger node.

**How it Works**

n8n includes a built-in node for Certificate Manager, SaaS (listed in n8n as Venafi TLS Protect Cloud) that can create certificate requests and get, download, renew and delete certificates, plus a trigger node that starts a workflow from Certificate Manager, SaaS events. You combine these nodes with the n8n integrations for the systems that consume certificates. See the Documentation tab for node details.
