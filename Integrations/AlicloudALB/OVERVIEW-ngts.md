# Alicloud ALB

Organizations that run applications on Alibaba Cloud terminate HTTPS on the Alibaba Cloud Application Load Balancer (ALB). Uploading and assigning certificates to each ALB by hand is slow, and a missed renewal causes an outage.

Secur Solutions' integration for Next-Gen Trust Security automates the certificate lifecycle for AliCloud ALB. Next-Gen Trust Security issues and renews certificates under your policy, then provisions them to the load balancer without manual steps.

**Value Highlights**

- **Automate provisioning** of TLS certificates to AliCloud ALB.
- **Upload and assign certificates** to the load balancer as part of each renewal.
- **Prevent outages** by replacing certificates before they expire.
- **Enforce policy** on the certificates that protect your Alibaba Cloud applications.
- **Manage Alibaba Cloud certificates** alongside the rest of your inventory in Next-Gen Trust Security.

**How it Works**

The integration is a machine connector for Next-Gen Trust Security. When a certificate is issued or renewed, the connector uploads the certificate and private key to Alibaba Cloud and assigns it to the ALB configured on the machine. Contact Secur Solutions for setup documentation.

**Solution Components**

- Next-Gen Trust Security with a machine connector from Secur Solutions
- Alibaba Cloud Application Load Balancer
