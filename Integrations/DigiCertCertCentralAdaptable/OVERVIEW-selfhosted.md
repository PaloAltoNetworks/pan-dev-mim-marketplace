# DigiCert CertCentral Adaptable

DigiCert’s CertCentral ensures complete security for public trust certificates, or of your organization’s root(s) of trust for private PKI. Its unique and customized certificate profiles enable internal authentication using modern cryptography. DigiCert and Venafi work together to identify, manage and automate certificate deployment to stop certificate-related outages.
**SOLUTION HIGHLIGHTS**
- **Lower operational costs** by automating the full certificate lifecycle from issuance to revocation with the latest DigiCert APIs
- **Gain 360-degree visibility** into the demand, usage and workflow of certificate services
- **Strengthen security** by enforcing policies with automated workflows and detailed logging
- **Ensure organizational compliance** with automated workflow approvals, authorization and authentication
- **Full certificate lifecycle automation** from request, issuance and renewal to revocation
- **Integrated with the latest** native DigiCert CertCentral API interface
- **Out-of-the-box client**, OV and EV certificate support
- **Venafi Adaptable CA Driver** developed and supported by DigiCert
**SOLUTION OVERVIEW**
While Public Key Infrastructure (PKI) is at the core of Machine Identity Management, securing the keys and certificates that act as machine identities is becoming much more of a challenge. The volume and velocity of machines and public key certificates are increasing every day, as is the need to extend PKI authentication to an increasing range of machines—web services, new industry-specific technologies and IoT devices. And all of these must be secured without disruption.
Venafi and DigiCert are industry-leading innovators uniquely positioned to simplify complex PKI deployment for the world’s largest organizations. The combined solution enables organizations to customize and orchestrate TLS certificates and Machine Identity Management at machine speed and scale.
DigiCert is updating this driver frequently to enhance functionality in order to support translation of legacy Symantec order numbers to DigiCert order numbers. This adaptable driver also supports DigiCert "Divisions" and allows the end user to specify the ICA.
**HOW IT WORKS**
Custom Fields are used to provide the following information:
1. Product
2. ICA
3. Division
4. Locale
5. Server Platform
6. Organization
7. Order Validity Years
8. Order Validity Days
9. Order Validity Custom Expiration Date
10. Cert Validity Years
11. Cert Validity Days
12. Cert Validity Custom Expiration Date
13. Code Signing Provisioning Method
Please see the included README, Glossary and Release Notes for additional configuration information.
