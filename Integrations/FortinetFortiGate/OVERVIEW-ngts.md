# Fortinet FortiGate

For a firewall to provide maximum protection, it needs to perform deep-packet analysis of network traffic. That means decrypting TLS traffic with SSL Inspection Profile certificates, and those certificates must stay valid and trusted on every device.

Next-Gen Trust Security integrates with Fortinet FortiGate firewalls to manage the SSL Inspection Profile certificates used to unlock TLS traffic and detect threats, along with the certificate used by the FortiGate management interface.

**Value Highlights**

- **Streamline** certificate lifecycle operations for your FortiGate devices.
- **Enhance visibility** and compliance with corporate certificate policy.
- **Automate** certificate requests and distribution to improve efficiency.
- **Reduce threats and errors** through a uniform deployment process.

**How it Works**

Next-Gen Trust Security discovers, enrolls and installs certificates for FortiGate devices. An authenticated scan of the FortiGate device identifies certificates assigned to SSL Inspection Profiles and the SSL certificate used by the management interface portal, then creates and associates the corresponding certificate objects. Next-Gen Trust Security then manages the full certificate lifecycle, including renewal and installation on the FortiGate device. See the Documentation tab for machine setup and provisioning.

**Solution Components**

- Next-Gen Trust Security
- Fortinet FortiGate (NGFW)
