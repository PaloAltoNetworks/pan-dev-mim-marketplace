# Fortinet FortiGate

For a firewall to provide maximum protection, it needs to perform deep-packet analysis of network traffic. That means decrypting TLS traffic with SSL Inspection Profile certificates, and those certificates must stay valid and trusted on every device.

The FortiGate Adaptable Application lets Certificate Manager, Self-Hosted manage the SSL Inspection Profile certificates used to unlock TLS traffic and detect threats, along with the certificate used by the FortiGate management interface.

**Value Highlights**

- **Streamline** certificate lifecycle operations for your FortiGate devices.
- **Enhance visibility** and compliance with corporate certificate policy.
- **Automate** certificate requests and distribution to improve efficiency.
- **Reduce threats and errors** through a uniform deployment process.

**How it Works**

The FortiGate Adaptable Application is built on the Certificate Manager, Self-Hosted Adaptable framework and performs discovery, enrollment and installation of certificates for FortiGate devices. The Onboard Discovery service runs an authenticated scan on the FortiGate device to find certificates assigned to SSL Inspection Profiles and the SSL certificate used by the management interface portal. It creates certificate objects and associates them with Adaptable Application objects, so Certificate Manager, Self-Hosted can manage the full lifecycle, including renewal and installation on the device. See the Documentation tab for installation and configuration.
