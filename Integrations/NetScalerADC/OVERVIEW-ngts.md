# NetScaler ADC

Scaling the use of HTTPs encryption is more important than ever but becomes difficult to scale. Next-Gen Trust Security integrates with NetScaler ADC, the leading load balancers to make it easy to get started and fully automate the use of keys and certificates for load balancing ops teams.
Load balancers have become a primary conduit through which organizations manage and process communications with customers, partners, and employees. Because load balancers front end so many applications, they also host many machine identities that represent each backend application. In fact, there can be as many as 1,000 machine identities or more per load balancer. Due to the critical nature of the services load balancers handle and the scale of machine identities they host, it’s difficult to collect intelligence or manage the lifecycle of these machine identities without automation.
**SOLUTION HIGHLIGHTS**
- **Scale use of HTTPS** without difficult setup or maintenance 
- **Eliminate outages** with continuous key and certificate updates 
- **Reduce risk** of security incidents from improperly handled keys 
- **Gain the full benefits** of application delivery with complete automation 
- **Automated discovery** and setup of existing keys and certificates 
- **Fully automated** issuance and renewal
**GETTING STARTED**
This integration with NetScaler ADC is distributed with Certificate Manager, Self-Hosted. There’s no installation required. All you need to do is follow the documentation which provides the step-by-step configuration instructions to get it working. 
This capability comes as part of the Next-Gen Trust Security offering, which provides clear and self-explanatory instructions for a successful configuration to enable the capability to connect your NetScaler ADC deployments in your infrastructure. 
**ABOUT NetScaler ADC**
Formerly Citrix, NetScaler ADC is an application delivery controller that provides flexible delivery services for traditional, containerized and microservice applications from your data center or any cloud. NetScaler and Venafi have teamed to make it easy to get started and fully automate the use of keys and certificates for load balancing operations and prevent costly outages.
**ABOUT Venafi**
Venafi is the cybersecurity market leader in machine identity management, securing the cryptographic keys and digital certificates on which every business and government depends to deliver safe machine-to-machine communication. Organizations use Venafi key and certificate security to protect communications, commerce, critical systems and data, and mobile and user access.
