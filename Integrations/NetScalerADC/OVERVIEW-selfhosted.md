# NetScaler ADC

Load balancers front end many applications, so a single NetScaler ADC can host hundreds of certificates, one for each backend application it serves. Without automation it is hard to keep track of them all or renew them before they expire, and a missed renewal takes customer-facing services offline. Certificate Manager, Self-Hosted integrates with NetScaler ADC so load balancing teams can automate key and certificate management at scale.

**Value Highlights**

- **Scale HTTPS** without difficult setup or maintenance.
- **Eliminate outages** with continuous key and certificate updates.
- **Reduce risk** of security incidents from improperly handled keys.
- **Discover existing certificates** already in use on your NetScaler ADC appliances.
- **Automate issuance and renewal** end to end.

**How it Works**

The NetScaler driver is distributed with Certificate Manager, Self-Hosted, so there is nothing to install. You add your NetScaler ADC devices and application objects, and Certificate Manager, Self-Hosted installs and renews certificates on them according to policy. See the Documentation tab for the configuration guide.

**Solution Components**

- Certificate Manager, Self-Hosted
- NetScaler ADC (formerly Citrix ADC)

**About NetScaler**

[NetScaler](https://www.netscaler.com/) ADC, formerly Citrix ADC, is an application delivery controller that provides delivery services for traditional, containerized and microservice applications from your data center or any cloud.
