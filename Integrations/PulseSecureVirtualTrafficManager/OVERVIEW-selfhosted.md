# Pulse Secure Virtual Traffic Manager

Pulse Secure Virtual Traffic Manager (vTM), now part of Ivanti, is a software-based application delivery controller that load balances and secures traffic to business-critical applications. The TLS certificates deployed on vTM must be kept current to avoid application outages. This integration automates the provisioning and renewal of those machine identities.

**SOLUTION HIGHLIGHTS**

- Automate certificate provisioning and renewal on Pulse Secure vTM
- Eliminate outages caused by expired certificates
- Maintain a complete inventory of vTM machine identities in the Venafi Platform

**HOW IT WORKS**

This adaptable application driver connects to Pulse Secure vTM to install and renew TLS certificates and keys as part of the standard Certificate Manager lifecycle, keeping deployed machine identities up to date automatically.

**Certificate Manager, Self-Hosted is the product formerly known as Venafi Trust Protection Platform**
