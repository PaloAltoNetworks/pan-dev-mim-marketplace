# Imperva SecureSphere

Stopping threats before they reach and exploit your web applications is the reason Web Application Firewalls (WAF) are so important. To make sure WAFs can see inside of encrypted HTTPS traffic, Venafi makes it easy to unlock encrypted traffic and detect threats at the Imperva firewall.

  

**SOLUTION HIGHLIGHTS**

- **Get started fast **with existing key and certificate inventory 
- **Maximize WAF utilization **with full key and certificate discovery 
- **Maintain level of WAF protection** with fully automated lifecycle and key distribution 
- **Immediate distribution** of keys already discovered  
- **Automated distribution **of keys and certificates to enable WAF inspection and protection 
- **Automated distribution **of replacement keys when new keys are generated to maintain WAF protection 

  

**SOLUTION OVERVIEW**

Web application attacks deny services and steal sensitive data. Imperva Web Application Firewall (WAF) analyzes and inspects requests coming in to applications and stops these attacks. Venafi makes it easy to unlock encrypted traffic and detect threats at the Imperva firewall by ensuring keys are available.
