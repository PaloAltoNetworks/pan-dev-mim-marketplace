# Alicloud Private CA

Organizations that use Alibaba Cloud Private CA for internal PKI still need its certificates to follow enterprise policy and to be renewed on time. Requesting and deploying them outside your certificate management platform leaves gaps in visibility and automation.

Secur Solutions' integration connects Next-Gen Trust Security to Alibaba Cloud Private CA. You can issue, renew and deploy private certificates from Alibaba Cloud while Next-Gen Trust Security enforces security policy, compliance and automation.

**Value Highlights**

- **Automate issuance and renewal** of certificates from Alibaba Cloud Private CA within Next-Gen Trust Security workflows.
- **Connect directly** to Alibaba Cloud Private CA for private certificate lifecycle operations.
- **Handle full chains** so the leaf, intermediate and root certificates are provisioned for trusted validation.
- **Enforce policy** and reduce manual work, expirations and misconfigurations.
- **Centralize visibility** of Alibaba Cloud private certificates with the rest of your inventory.

**How it Works**

The integration is a CA connector for Next-Gen Trust Security, built on the CA connector framework. It connects to Alibaba Cloud Private CA to submit requests, retrieve issued certificates with their full chain, and support renewal, so private certificates follow the same issuing policies as your other CAs. Contact Secur Solutions for setup documentation.

- Next-Gen Trust Security with a CA connector from Secur Solutions
- Alibaba Cloud Private CA
