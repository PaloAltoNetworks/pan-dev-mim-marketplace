**Note: this script can be used, but it has been added to VenafiPS as Search-TppHistory with the ability to search on all attributes, not just active.**

# Get-TppActiveHistoricalCertificate

Find active/valid historical certificates in TPP

## Getting started

Ensure you have the VenafiPS powershell module installed, v4.2.0 or later.
The Powershell environment must be v7 or later.

## Usage

- Create a new tpp session with New-VenafiSession
- Execute the script according to the help
