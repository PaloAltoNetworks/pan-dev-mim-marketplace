# DigiCert CertCentral

DigiCert CertCentral issues and manages publicly trusted TLS/SSL certificates. Next-Gen Trust Security includes DigiCert CertCentral as a built-in certificate authority (CA), so teams can request and renew DigiCert certificates under central policy without custom scripting.

**Value Highlights**

- **Use a built-in CA**: Add DigiCert CertCentral as a CA connection in Next-Gen Trust Security with no scripts or extra software.
- **Automate the lifecycle**: Handle request, issuance, renewal and revocation from one place.
- **Issue OV and EV certificates**: Use DigiCert's Organization Validated and Extended Validation certificate products.
- **Make the most of prepaid coverage**: Control when Next-Gen Trust Security renews a DigiCert order instead of reissuing a shorter-lived certificate under it.
- **Choose your region**: Connect to DigiCert's United States or European Union servers.
- **Get support from one vendor**: The integration is built and supported by Venafi.

**How it Works**

An administrator adds DigiCert as a certificate authority in Next-Gen Trust Security using DigiCert CertCentral API credentials, then sets a renewal window and a minimum certificate validity. Request policies map to DigiCert certificate products, and Next-Gen Trust Security sends certificate requests to CertCentral and retrieves the issued certificates. For DV certificates, use an ACME CA connection instead. See the Documentation tab for setup.

**Solution Components**

- DigiCert CertCentral account with pre-purchased units or post-use billing
