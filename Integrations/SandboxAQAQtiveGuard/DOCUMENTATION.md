# SandboxAQ AQtive Guard

## Prerequisites

- Certificate Manager, Self-Hosted, with a user that can obtain an access token
- SandboxAQ AQtive Guard

## Configuration

1. Obtain your Certificate Manager, Self-Hosted instance URL and an access token.
2. In AQtive Guard, open the **Integrations** tab and enter the URL and access token.

## Usage

1. Trace an application or scan a file system, and upload the resulting trace to AQtive Guard.
2. Generate a report in AQtive Guard.
3. In the **Certificates** tab of the report, click **Populate Venafi GUIDs** to look up all certificates in the Certificate Manager, Self-Hosted inventory.
4. For certificates already in the inventory, click through to the record or view selected details in AQtive Guard.
5. For certificates not found in the inventory, review the details and, if you wish, upload them to Certificate Manager, Self-Hosted with a single click.
