# ServiceNow Event Creation

This log driver will take any Certificate Manager log event and create a ServiceNow Event Management event from it.

  

**SOLUTION HIGHLIGHTS**

- **Complete customization** allows any Venafi event to be translated to and acted upon from ServiceNow
- **Eliminates the need **to create manual notifications/alerts in separate systems for different teams
- **Provides visibility **to teams that don't have direct access to Venafi

  

**SOLUTION OVERVIEW**

This log driver will take any Certificate Manager log event and create a ServiceNow Event Management event from it. Events, via [event rules](https://docs.servicenow.com/bundle/rome-it-operations-management/page/product/event-management/concept/create-event-rules.html), are used to initiate [alerts](https://docs.servicenow.com/bundle/rome-it-operations-management/page/product/event-management/concept/c_EMAlert.html) which can be configured to perform any number of actions and can help organizations to identify root causes for unexpected behavior, understand the impact that behavior has on the rest of the company, and finally help to improve overall availability of Venafi services.

**Certificate Manager, Self-Hosted is the product formerly known as Venafi Trust Protection Platform**
