# Automation for Ping Identity

The Ping Identity suite provides advanced authentication for organizations, and it depends on X.509 certificates to do so. Without a way to monitor and automate those certificates, they are managed by hand, which causes application access issues, outages and a larger attack surface. Compromised machine identities can grant unauthorized access to a broad range of enterprise applications.

This integration, built by IDMWORKS, connects Certificate Manager, Self-Hosted to PingFederate and PingAccess. It automates the lifecycle of the keys and certificates that Ping Identity products use, from discovery and generation to installation and retirement.

**Value Highlights**

- **Automate key and certificate management** for PingFederate and PingAccess.
- **Prevent outages and access issues** caused by expired certificates.
- **Reduce the overhead** of applying key management best practices across the Ping Identity platform.
- **Protect sensitive authentication traffic**, such as credentials and B2B or B2C authentication, with properly managed keys.
- **Scale securely** as new Ping Identity components are added.

**How it Works**

The integration is an Adaptable Application driver for Certificate Manager, Self-Hosted. After you obtain the license and download from IDMWORKS, you install and configure it with the standard Adaptable Application driver process. Detailed technical instructions come with the driver download. See the Documentation tab for the Adaptable Application driver setup guide.

**Applicability**

Any organization that relies on the Ping Identity platform without a fully automated way to manage the keys and certificates behind it should consider this integration.

**Solution Components**

- Certificate Manager, Self-Hosted 21.4 or later
- PingFederate 10 or later
- PingAccess 6 or later
