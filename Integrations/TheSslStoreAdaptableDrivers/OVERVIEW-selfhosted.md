# The SSL Store

Buying and replacing public certificates from several CAs by hand is slow, expensive and easy to get wrong. These Adaptable CA drivers from The SSL Store let Certificate Manager, Self-Hosted order certificates through The SSL Store, so you can automatically replace weak or expiring keys and certificates at a fraction of the cost of a traditional managed PKI platform.

**Value Highlights**

- **Automate certificate replacement**: Rotate keys and replace certificates automatically to prevent outages.
- **Respond quickly**: Remediate certificates in bulk with automation in the case of a breach.
- **Lower costs**: Benefit from reseller pricing while reducing labor and operational expenses.
- **Choose from multiple products**: Order Comodo (Sectigo) EV, multi-domain and wildcard, InstantSSL and PositiveSSL certificates.
- **Get an independent advocate**: The SSL Store helps you resolve issues and meet new requirements regardless of the CA brand you choose.

**How it Works**

Each product has its own Adaptable CA driver (a PowerShell script). The drivers authenticate to The SSL Store API with your Partner Code and Auth Token and submit orders using the organization and validation details set on the certificate. Set the admin contact defaults in each script before use. See the Documentation tab for parameters and configuration.

**Solution Components**

- Certificate Manager, Self-Hosted
- The SSL Store account (Partner Code and Auth Token)
- The SSL Store Adaptable CA drivers
