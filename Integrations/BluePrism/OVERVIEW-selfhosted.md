# Blue Prism

The Blue Prism Connector for Certificate Workflow lets Blue Prism digital workers automate certificate lifecycle tasks in Certificate Manager, Self-Hosted through the platform’s Web SDK, so routine machine identity work can be handled by RPA at scale.

  

**SOLUTION HIGHLIGHTS**

- **Automate **certificate workflow actions using Blue Prism digital workers
- **Eliminate time spent **on manual certificate updates and pending-certificate handling
- **Scale certificate lifecycle automation **across a growing number of machine identities

  

**SOLUTION OVERVIEW**

The integration connects Blue Prism’s robotic process automation platform with Venafi’s Certificate Manager, Self-Hosted using the Trust Protection Platform Web SDK. Delivered as a Blue Prism solution template by Reveal Group, it enables digital workers to action pending certificates and drive certificate workflows through API calls. Because it is built on the Web SDK, the template can be expanded or altered with additional components to fit an organization’s specific certificate lifecycle processes, from request and renewal to deployment and revocation.

**ABOUT BLUE PRISM**

Blue Prism, part of SS&C, is an intelligent automation and robotic process automation (RPA) platform that lets organizations build a digital workforce to execute rules-based business processes. Its digital workers integrate with enterprise applications and APIs to automate repetitive tasks, improving efficiency, accuracy, and scalability across the enterprise.

**Certificate Manager, Self-Hosted is the product formerly known as Venafi Trust Protection Platform**
