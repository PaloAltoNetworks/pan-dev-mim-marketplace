# Broadcom SSL Visibility Appliance

The Broadcom SSL Visibility Appliance decrypts and inspects SSL/TLS traffic for threat analysis. To inspect traffic without gaps, the appliance needs the current set of keys and certificates, and distributing those keys by hand is slow and error prone.

Venafi and Broadcom (formerly Symantec) have partnered so Certificate Manager, Self-Hosted distributes keys and certificates to the appliance automatically, keeping inspection complete as keys change.

**Value Highlights**

- **Get started quickly**: Use your existing key and certificate inventory from the start.
- **Maximize inspection**: Discover keys and certificates so the appliance can inspect more traffic.
- **Maintain inspection levels**: Automate the key and certificate lifecycle and key distribution.
- **Distribute replacement keys automatically**: Send new keys to the appliance as soon as they are generated.
- **Improve inspection performance**: Remove delays caused by manual key distribution.

**How it Works**

Certificate Manager, Self-Hosted discovers keys and certificates and builds a complete machine identity inventory. It then distributes the current keys and certificates to the Broadcom SSL Visibility Appliance, including replacement keys when new keys are generated, so the appliance can keep decrypting and inspecting traffic. Contact Broadcom for setup details.
