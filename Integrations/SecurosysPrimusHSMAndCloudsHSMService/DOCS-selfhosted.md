## Installation

1. Download the Securosys Primus PKCS#11 provider and its documentation from the Securosys Support Portal.
2. Install and configure the Securosys Primus PKCS#11 provider on each Certificate Manager, Self-Hosted server in the cluster.
3. Establish redundant connectivity from each server to your closest HSM cluster members.

## Configuration

- [Primus HSM - PKCS#11 Provider User Guide](https://support.securosys.com/external/knowledge-base/article/65): detailed installation and configuration instructions for the provider.
- [Integration Guide: Securing Certificate Manager, Self-Hosted](https://support.securosys.com/external/knowledge-base/article/64#AN-PKCS): steps to connect Certificate Manager, Self-Hosted to Primus HSM or CloudsHSM.
- See the Certificate Manager, Self-Hosted HSM integration documentation on [docs.venafi.com](https://docs.venafi.com/) for the product-side configuration.
