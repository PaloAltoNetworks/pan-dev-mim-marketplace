# Apache Kafka

The Venafi Kafka Connector provides a standardized way to extract security events from the Venafi Platform and make them available for further analysis, filtering and processing within Kafka and its broader ecosystem.

  

**SOLUTION HIGHLIGHTS**

- **Get real time data processing **with configurable analysis of Venafi security events
- **Enjoy flexible integration **with other systems by easily sending Venafi events into any downstream analysis tool capable of consuming data from Kafka
- **Full event coverage **generated by the Venafi Platform
- **Available as open source **under the popular Apache 2.0 license, and is also officially Confluent (Kafka) verified 

  

**SOLUTION OVERVIEW**

Developed by OpenCredo, the open source Kafka connector for Venafi provides a standard way to extract security events from the Venafi Platform and make them available for further analysis and processing via Kafka. It enables flexible intelligent real-time processing of security and machine identity data by a variety of different Kafka consumers - regardless of whether the target is a downstream SIEM, a new real-time machine learning platform or some combination thereof.
