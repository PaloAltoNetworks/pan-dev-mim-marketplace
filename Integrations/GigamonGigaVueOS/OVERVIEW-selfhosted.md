# Gigamon GigaVue (OS)

The Gigamon/Venafi integration provides intelligent orchestration and management of machine identities for Gigamon appliance web management interfaces.

  

**SOLUTION HIGHLIGHTS**

- **Ensure confidentiality and integrity **of communications
- **Streamline operations** by eliminating manual provisioning
- **Increase security posture **with properly identified machine identities
- **Prevent downtime and outages** caused by expired certifictates
- **Create, renew, verify & revoke** machine identities for GigaVUE-OS web management interface
- **Fully automate **certificate renewal and deployment for Gigamon devices
- **Eliminate self-signed certificates **and browser issues

  

**SOLUTION OVERVIEW**

The Gigamon – Venafi integration provides intelligent orchestration and management of machine identities for Gigamon appliance web management interfaces. Our other Gigamon integration handles automated provisioning of machine identities used in Gigamon policies for TLS inspection, but the Gigamon admin UI also uses a machine identity to secure communication. 

  

Usually, that certificate is self-signed, or requires manual intervention when it expires. With this integration, Gigamon administrators no longer need to worry about managing the lifecycle of the UI certificate. 

**Certificate Manager, Self-Hosted is the product formerly known as Venafi Trust Protection Platform**
