# AWS Elastic Load Balancer

Machine identities play a major role in securing the traffic through a load balancer in modern cloud architectures. An Load Balancer functions at the application layer and serves as the single point of contact for clients to distribute incoming application traffic across multiple targets, such as EC2 instances, in multiple Availability Zones. Certificate Manager supports the provisioning of certificates and keys to AWS Load Balancers.
