# Auto-Enrollment Connector

Hydrant ID has built a connector that enables Venafi customers to provide a single machine identity management service including Windows auto-enrollment connected endpoints.

  

**SOLUTION HIGHLIGHTS**

- **Get started fast **with inventories of existing keys and certificates 
- **Gain full, instant visibility **over all machine identities for Windows infrastructure 
- **Automate issuance **for Windows endpoints 
- **Control all machine identities **for Windows ** **
- **Eliminate the need **for any agents

  

**SOLUTION OVERVIEW**

With sponsorship from the Machine Identity Management Development Fund, HID Global, who provides highly scalable and secure Manager PKI services, has built an Auto-Enrollment Connector for the Venafi Platform. Until now security teams have been unable to consolidate issuance, policy, and automation for machine identities using the Microsoft Auto-enrollment protocol. With the HydrantID Connector, Venafi customers have a single machine identity management service that includes auto-enrollment for Windows connected endpoints.  

**Certificate Manager, Self-Hosted is the product formerly known as Venafi Trust Protection Platform**
