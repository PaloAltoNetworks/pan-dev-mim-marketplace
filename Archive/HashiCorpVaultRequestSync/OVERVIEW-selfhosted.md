# HashiCorp Vault Request Sync

This is a CLI tool that helps manage machine identities located in Certificate Manager, Self-Hosted and HashiCorp Vault.
**SOLUTION HIGHLIGHTS**
- **Enable InfoSec and AppDev** teams to work together effortlessly
- **Gain visibility and intelligence** of machine identities in use by HashiCorp Vault
- **Ensure synchronicity** of machine identities between Venafi and HashiCorp Vault
- **Perform critical tasks** around machine identity lifecycle directly from HashiCorp Vault CLI
**SOLUTION OVERVIEW**
This CLI tool helps manage machine identities located in Certificate Manager, Self-Hosted and HashiCorp Vault. It provides a user with a single convenient interface to manage two separate systems with a few, commonly used commands, like 'login', 'create', 'revoke', and 'list'. Secrets can be created in either location and synced to the other.

**Certificate Manager, Self-Hosted is the product formerly known as Venafi Trust Protection Platform**
