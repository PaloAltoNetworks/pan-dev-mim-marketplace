# Secrets Engine for HCP Vault (HashiCorp Cloud Platform)

This integration is delivered as a Vault plugin on HashiCorp Cloud Platform (HCP), allowing DevOps teams to acquire and consume machine identities from Next-Gen Trust Security in addition to Vault’s built-in PKI, without altering their interaction with Vault.

  

**Applicability**

Organizations using HCP Vault to issue certificates for development, testing, and deployment should consider adopting this plugin.

  

**Additional Resources**

Github repo: [https://github.com/Venafi/vault-pki-backend-venafi](https://github.com/Venafi/vault-pki-backend-venafi)

  

**Get it to work **

The Venafi secrets engine for Vault is open-source software that leverages Vault’s plugin framework. The Venafi plugin is available on HCP through the Vault Integrations page, where it will be automatically installed. After installation, you can set up the plugin by following the instructions provided by HCP.

  

Step-by-step configuration details are available in the documentation associated with the listing.
